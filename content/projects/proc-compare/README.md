# ProcCompare

Comparador de procedures T-SQL entre ambientes, com normalização e alinhamento de diferenças.

## Contexto

Instituição financeira do setor bancário. Apoio a mudanças e reuniões de liberação.

## Objetivo

Tornar divergências entre fornecedor e produção visíveis antes do change.

## Stack

TypeScript, T-SQL, Zod, Vite, Vitest.

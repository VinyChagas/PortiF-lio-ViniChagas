# Coletor de solicitações operacionais

Automação de extração em lote de registros de atendimento, históricos e anexos de um portal legado.

## Contexto

Instituição financeira do setor bancário. Sustentação de sistemas financeiros.

## Objetivo

Coletar de forma repetível dados gerais, histórico paginado e anexos por solicitação operacional, com exportação organizada.

## Stack

Node.js, Express, Selenium, SSE; apoio complementar com LLM local para resumos.

# Plataforma Unificada de Sustentação

Shell que reúne gestor de solicitações, coletor de históricos e ProcCompare.

## Contexto

Instituição financeira do setor bancário.

## Objetivo

Oferecer uma experiência operacional única sem fundir os motores de cada ferramenta.

## Stack

React, Vite, Node.js, Express, Selenium, JWT.

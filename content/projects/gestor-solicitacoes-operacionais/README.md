# Gestor de solicitações operacionais

Central de acompanhamento que vincula chamados internos a registros do fornecedor.

## Contexto

Instituição financeira do setor bancário. Operação de sustentação.

## Objetivo

Unificar a visão operacional entre portal interno e portal do fornecedor, detectando atualizações relevantes.

## Stack

TypeScript, React, Selenium, WebSocket, API REST.
